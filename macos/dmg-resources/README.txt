Prism for Mac
=============

Recommended install (avoids "damaged app" warnings):

  1. Double-click "Install Prism.command"
  2. If macOS asks, click Open
  3. Follow the setup window in Prism

Manual install:

  1. Drag Prism.app to Applications
  2. If macOS says Prism is damaged, open Terminal and run:
       xattr -cr /Applications/Prism.app
  3. Open Prism from Applications

Requirements: Python 3.10+, Claude Desktop

Docs: https://kushals256.github.io/mcp-server/install/
